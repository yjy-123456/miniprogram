# 王者农场助手微信小程序开发计划

## 1. 产品目标

把现有 HTML 原型落成微信小程序，定位为“王者农场玩法攻略查询工具”。第一版重点不是社区和复杂后台，而是让玩家快速完成四件事：

- 搜索“今天种什么、12级种什么、小摊还是升地”等问题，得到直接建议。
- 查看作物图鉴，按冲级、赚钱、突变、订单筛选。
- 计算或比较种植收益，选择日常、睡前、周末双倍方案。
- 查看小摊、开地、二级地的升级优先级。

## 2. MVP 范围

### 首页

- 顶部农场氛围图和日期信息。
- 搜索框与热门搜索词。
- 今日推荐卡片：作物/策略、收益、成熟时间、推荐理由。
- 作物收益横向对比。
- 周末双倍提醒。

### 作物图鉴

- 分类筛选：全部、冲级、赚钱、突变、订单。
- 作物列表：图片、解锁等级、用途、经验、收益。
- 当前作物详情卡。
- 突变形态示例。

### 收益推荐

- 目标切换：稳收、冲级、赚钱。
- 当前条件卡：等级、地块数、小摊等级。
- 方案列表：日常稳收、睡前托管、周末冲刺。
- 周末双倍提醒。

### 小摊升级

- 当前建议：先升小摊到 13 级。
- 升级步骤：小摊、开地、二级地。
- 开地对比说明。
- 生成路线入口，后续接入玩家输入数据。

## 4. 技术路线

### 第一阶段：本地小程序原型

- 使用原生微信小程序：WXML + WXSS + JS。
- 不接后端，不接登录。
- 使用本地 `utils/data.js` 维护攻略与作物数据。
- 使用 tabBar 搭建四个核心页面。
- 用微信开发者工具导入 `miniprogram/` 所在工程预览。

### 第二阶段：可维护数据后台

- 接入微信云开发。
- 建立 `crops`、`advices`、`plans`、`mutations`、`versions` 集合。
- 增加管理端或云函数导入脚本。
- 页面读取云数据库，保留本地数据作为兜底。

### 第三阶段：查询与计算增强

- 收益计算器支持输入等级、地块数、小摊等级、在线时间。
- 搜索支持同义词和问题模板，例如“12级种啥”“先摊还是地”。
- 增加收藏、最近查看、提醒配置。

### 第四阶段：运营与合规

- 数据展示加入版本号、更新时间、来源说明。
- 明确“非官方攻略工具，数据仅供参考”。
- 避免使用官方游戏图标、英雄肖像、原 UI 素材。
- 不提供自动收菜、脚本、多开等违规能力。

## 5. 当前交付

当前已创建 `miniprogram/` 原生微信小程序初版工程，包含：

- `app.json`、`app.wxss`、`app.js`
- 四个页面：`index`、`atlas`、`profit`、`stall`
- 公共数据：`utils/data.js`
- 复用原型生成的原创农场和作物图片资源

## 6. 后续开发优先级

1. 接入真实作物数据和版本更新记录。
2. 首页搜索改成关键词匹配 + 结果页。
3. 收益页加入可输入参数的计算器。
4. 图鉴页加入作物详情二级页。
5. 小摊页加入回本周期计算。
6. 接入云开发，支持数据热更新。
