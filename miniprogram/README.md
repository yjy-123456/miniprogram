# 王者农场助手小程序

这是根据 `prototype/` 原型落成的原生微信小程序初版工程。

## 如何预览

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择：

```text
/Users/yangjianyong/Documents/王者农场/miniprogram
```

4. AppID 可先使用测试号或替换 `project.config.json` 中的 `appid`。
5. 编译后可在模拟器查看四个 Tab 页面。

## 已实现页面

- 首页：攻略搜索、热门问题、今日推荐、作物收益对比、周末双倍提醒。
- 作物图鉴：分类筛选、作物列表、当前作物详情、突变形态。
- 收益：目标切换、当前条件、收益方案、周末提醒。
- 小摊：升级建议、优先级步骤、开地对比、生成路线提示。

## 数据位置

当前使用本地静态数据：

```text
utils/data.js
```

后续可以迁移到微信云开发数据库，并保留本地数据作为兜底。
